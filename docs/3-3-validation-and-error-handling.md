# 入力チェック・エラー処理設計

## 1. 概要

本書では、空間メモにおける入力チェック、エラー表示、通信失敗時の処理を定義する。

不正なデータの保存を防ぎ、ユーザーがエラーの原因と対処方法を理解できる表示を行う。

## 2. 共通方針

- 保存前に入力内容を検証する
- 文字列の先頭と末尾にある不要な空白を削除する
- 入力に問題がある場合は保存処理を開始しない
- エラーが発生しても入力途中の内容を可能な限り保持する
- 通信中は保存ボタンなどを無効化する
- 通信中は`ProgressView`を表示する
- FirebaseやCloudinaryのエラーをそのまま表示しない
- ユーザーが理解できる日本語のメッセージへ変換する
- API Secret、IDトークン、パスワードなどをログへ出力しない

## 3. アカウント登録の入力チェック

| 項目 | 必須 | 入力条件 | エラーメッセージ |
|---|:---:|---|---|
| ユーザー名 | ○ | 1文字以上30文字以内 | ユーザー名を1文字以上30文字以内で入力してください。 |
| メールアドレス | ○ | メールアドレス形式 | 正しいメールアドレスを入力してください。 |
| パスワード | ○ | 8文字以上64文字以内 | パスワードを8文字以上64文字以内で入力してください。 |
| パスワード確認 | ○ | パスワードと一致 | パスワードが一致していません。 |

入力項目がすべて有効になるまで、登録ボタンを無効化する。

## 4. ログインの入力チェック

| 項目 | 必須 | 入力条件 | エラーメッセージ |
|---|:---:|---|---|
| メールアドレス | ○ | メールアドレス形式 | 正しいメールアドレスを入力してください。 |
| パスワード | ○ | 空文字ではない | パスワードを入力してください。 |

ログインに失敗した場合でも、メールアドレスまたはパスワードのどちらが間違っているかは区別せず、次のメッセージを表示する。

```text
メールアドレスまたはパスワードが正しくありません。
```

## 5. 部屋登録の入力チェック

| 項目 | 必須 | 入力条件 | エラーメッセージ |
|---|:---:|---|---|
| 部屋名 | ○ | 1文字以上50文字以内 | 部屋名を1文字以上50文字以内で入力してください。 |
| 部屋写真 | ○ | 対応形式の画像 | 部屋の写真を選択してください。 |
| 画像サイズ | ○ | 10MB以下 | 10MB以下の画像を選択してください。 |

対応する画像形式は次のとおりとする。

- JPEG
- PNG
- HEIC

部屋名と写真が有効になるまで、保存ボタンを無効化する。

## 6. メモの入力チェック

| 項目 | 必須 | 入力条件 | エラーメッセージ |
|---|:---:|---|---|
| タイトル | ○ | 1文字以上100文字以内 | タイトルを1文字以上100文字以内で入力してください。 |
| メモ本文 |  | 2,000文字以内 | メモは2,000文字以内で入力してください。 |
| pinX | ○ | `0.0`以上`1.0`以下 | メモの位置が正しくありません。 |
| pinY | ○ | `0.0`以上`1.0`以下 | メモの位置が正しくありません。 |
| ピンカラー | ○ | 定義済みの10色 | ピンカラーを選択してください。 |
| 添付写真 |  | 対応形式かつ10MB以下 | 10MB以下の対応画像を選択してください。 |

メモ本文と添付写真は任意項目とする。

## 7. 共有メンバー追加の入力チェック

| 条件 | エラーメッセージ |
|---|---|
| メールアドレスが空 | メールアドレスを入力してください。 |
| メールアドレス形式ではない | 正しいメールアドレスを入力してください。 |
| 登録済みユーザーが存在しない | 該当するユーザーが見つかりません。 |
| 自分自身を追加しようとした | 自分自身を共有メンバーに追加することはできません。 |
| すでに共有されている | このユーザーとはすでに部屋を共有しています。 |
| 所有者以外が追加しようとした | 共有メンバーを追加する権限がありません。 |

## 8. エラーの分類

| 分類 | 内容 | 表示方法 |
|---|---|---|
| 入力エラー | 未入力、文字数超過、形式不正 | 入力欄の近くへ表示 |
| 認証エラー | ログイン失敗、認証切れ | 画面内またはアラート |
| 権限エラー | 操作権限がない | アラート |
| データ未検出 | 部屋やメモが存在しない | アラート後に前画面へ戻る |
| 重複エラー | 共有ユーザーが登録済み | 入力欄の近くへ表示 |
| 通信エラー | インターネット接続失敗 | 再試行可能なアラート |
| 画像エラー | 選択、読込、アップロード失敗 | アラート |
| 不明なエラー | 想定外の処理失敗 | 共通エラーメッセージ |

## 9. エラーコードと表示メッセージ

| エラーコード | 表示メッセージ |
|---|---|
| INVALID_EMAIL | 正しいメールアドレスを入力してください。 |
| INVALID_PASSWORD | パスワードの入力内容を確認してください。 |
| LOGIN_FAILED | メールアドレスまたはパスワードが正しくありません。 |
| NETWORK_ERROR | 通信に失敗しました。インターネット接続を確認してください。 |
| UNAUTHORIZED | ログイン情報の有効期限が切れました。もう一度ログインしてください。 |
| FORBIDDEN | この操作を行う権限がありません。 |
| USER_NOT_FOUND | 該当するユーザーが見つかりません。 |
| ROOM_NOT_FOUND | 指定された部屋が見つかりません。 |
| MEMO_NOT_FOUND | 指定されたメモが見つかりません。 |
| MEMBER_ALREADY_EXISTS | このユーザーとはすでに部屋を共有しています。 |
| INVALID_IMAGE | 選択した画像を使用できません。 |
| IMAGE_UPLOAD_FAILED | 画像のアップロードに失敗しました。 |
| SAVE_FAILED | 保存に失敗しました。もう一度お試しください。 |
| UNKNOWN_ERROR | エラーが発生しました。もう一度お試しください。 |

## 10. 画面別エラー処理

### ログイン画面

- 入力エラーは入力欄の下へ表示する
- 認証失敗はログインボタンの近くへ表示する
- ログイン処理中はログインボタンを無効化する

### アカウント登録画面

- 各入力エラーを対象入力欄の下へ表示する
- 登録処理中は登録ボタンを無効化する
- Firebase Authenticationへの登録とユーザー情報の保存が完了してから画面を移動する

### 部屋一覧画面

- 読み込み中は`ProgressView`を表示する
- 部屋が0件の場合は「部屋がまだ登録されていません」と表示する
- 取得失敗時は再読み込みボタンを表示する

### 部屋登録画面

- Cloudinaryへの画像アップロード成功後にFirestoreへ部屋情報を保存する
- 画像アップロードに失敗した場合はFirestoreへ保存しない
- 保存中は保存ボタンとキャンセルボタンを無効化する

### 部屋詳細画面

- 部屋が存在しない場合はメッセージを表示して部屋一覧画面へ戻る
- メモの取得に失敗した場合は部屋画像を表示し、メモの再読み込みを案内する
- editorには権限のない操作を表示しない

### メモ編集画面

- 入力エラーがある場合は保存を開始しない
- 添付画像がある場合は画像アップロード後にFirestoreへ保存する
- 画像アップロードに失敗した場合はメモを保存しない
- 保存失敗時は入力中の内容を保持する

### 共有管理画面

- owner以外がアクセスした場合は部屋詳細画面へ戻す
- ユーザーが見つからない場合は入力したメールアドレスを保持する
- 共有成功後に共有メンバー一覧を更新する

### 設定画面

- ユーザー情報の取得に失敗した場合は再読み込みを案内する
- ログアウト失敗時はログイン状態を維持する

## 11. ローディング状態

通信処理中は、同じ操作が複数回実行されないようにする。

| 処理 | 制御 |
|---|---|
| ログイン | ログインボタンを無効化 |
| アカウント登録 | 登録ボタンを無効化 |
| 部屋登録 | 保存ボタンを無効化 |
| メモ保存 | 保存ボタンを無効化 |
| 共有メンバー追加 | 共有ボタンを無効化 |
| 画像アップロード | 写真の再選択と保存を無効化 |

## 12. CloudinaryとFirestoreの処理順序

画像を含むデータは次の順番で保存する。

```text
画像を選択
  ↓
入力チェック
  ↓
Cloudinaryへ画像をアップロード
  ↓
imageUrlとimagePublicIdを取得
  ↓
Firestoreへデータを保存
```

Cloudinaryへのアップロードに失敗した場合は、Firestoreへの保存を実行しない。

Cloudinaryへのアップロード後にFirestoreへの保存が失敗した場合、画像だけがCloudinaryに残る可能性がある。MVPではエラーを表示し、不要画像の自動削除は将来機能とする。

## 13. 認証期限切れ

Firebase Authenticationの認証情報が無効になった場合は、次の処理を行う。

1. 実行中の処理を中止する
2. 「ログイン情報の有効期限が切れました」と表示する
3. ログイン画面へ移動する
4. 再ログインを案内する

## 14. ログ出力

開発中はエラー調査のためにログを使用する。ただし、次の情報をログへ出力しない。

- パスワード
- Firebase IDトークン
- Cloudinary API Secret
- ユーザーの入力したメモ本文
- 不要なメールアドレス
- 写真データ

リリース時にはデバッグ用の不要なログを削除する。
