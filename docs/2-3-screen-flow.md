
# 画面遷移図

## 1. 概要

空間メモにおける主要画面の遷移を示す。

本図では主要な画面への遷移を対象とし、保存後の復帰、戻る、キャンセルなどの一般的な戻り操作は省略する。

## 2. 画面遷移図

### 2.1 ログイン・部屋選択

![画面遷移図 1ページ目](../images/screen-flow-1.png)

対象となる画面は次のとおり。

- SCR-001 ログイン画面
- SCR-002 アカウント登録画面
- SCR-003 部屋一覧画面
- SCR-004 部屋登録画面
- SCR-005 部屋詳細画面
- SCR-008 設定画面

### 2.2 部屋詳細・メモ・共有

![画面遷移図 2ページ目](../images/screen-flow-2.png)

対象となる画面は次のとおり。

- SCR-005 部屋詳細画面
- SCR-006 メモ編集画面
- SCR-007 共有管理画面
- 写真選択画面（PhotosUI標準画面）

## 3. 主な画面遷移

| 遷移元 | 操作 | 遷移先 |
|---|---|---|
| SCR-001 ログイン画面 | 新規登録をタップ | SCR-002 アカウント登録画面 |
| SCR-001 ログイン画面 | ログインに成功 | SCR-003 部屋一覧画面 |
| SCR-002 アカウント登録画面 | アカウント登録に成功 | SCR-003 部屋一覧画面 |
| SCR-003 部屋一覧画面 | 追加ボタンをタップ | SCR-004 部屋登録画面 |
| SCR-003 部屋一覧画面 | 部屋写真をタップ | SCR-005 部屋詳細画面 |
| SCR-003 部屋一覧画面 | 設定ボタンをタップ | SCR-008 設定画面 |
| SCR-005 部屋詳細画面 | 追加ボタンから「メモを追加」を選択し、位置をタップ | SCR-006 メモ編集画面 |
| SCR-005 部屋詳細画面 | 既存のメモピンをタップ | SCR-006 メモ編集画面 |
| SCR-005 部屋詳細画面 | 共有ボタンをタップ | SCR-007 共有管理画面 |
| SCR-005 部屋詳細画面 | 追加ボタンから「部屋画像を追加・変更」を選択 | 写真選択画面 |

## 4. 補足

- メモの新規登録と既存メモの編集には、同じメモ編集画面を使用する
- 写真選択画面にはiOS標準のPhotosUIを使用する
- 写真選択後は部屋詳細画面へ戻り、選択した画像を表示する
- 認証済みの場合はログイン状態を保持し、アプリ起動後に部屋一覧画面を表示する
- ownerだけが共有管理画面へ移動できる
- editorには共有ボタンと部屋画像変更操作を表示しない
