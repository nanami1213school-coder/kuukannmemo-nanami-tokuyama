## 1. アプリ概要

「空間メモ」は、部屋の写真上にピンを配置し、その場所に関連する情報を記録・管理できるiPhoneアプリである。

ピンには、タイトル、自由記載のメモ、ピンカラー、添付写真を登録できる。メモには、備品の保管場所、消耗品の在庫数、家具や設備の型番、現在の状態、故障日、修理予定日など、利用目的に応じた情報を自由に記録する。

保存した部屋とメモは複数端末で同期でき、他のユーザーと部屋単位で共有できる。

家庭だけでなく、ホテル、学校、会社など、部屋や備品の管理が必要な場所での利用を想定する。

## 2. 制作背景

家庭や施設では、備品の保管場所、消耗品の在庫数、家具や設備の型番、故障状況、修理予定など、管理しなければならない情報が多く存在する。

一般的なメモアプリでは情報を文章として記録できるが、その情報がどの部屋のどの場所に関係しているのかを直感的に把握しにくい。

また、管理情報が個人のメモや口頭での連絡に分散すると、補充忘れ、重複購入、点検漏れ、修理対応の遅れなどが発生する可能性がある。

## 3. 制作目的

部屋の写真上の位置とメモを結び付けることで、どの場所に何があり、どのような情報が登録されているのかを視覚的に把握できるようにする。

自由記載のメモ欄を設けることで、収納場所、在庫数、型番、故障状況、修理予定など、利用者や施設によって異なる情報を柔軟に記録できるようにする。

さらに、複数端末での同期と他のユーザーとの共有を可能にし、家庭や施設における情報管理と情報共有を効率化する。

## 4. 対象ユーザー

### 主な対象ユーザー

- 家庭内の収納場所や備品を管理したい人
- 消耗品の在庫状況を記録したい人
- 家具や家電の型番、状態、修理予定を管理したい人
- 家族と部屋の情報を共有したい人
- ホテルの客室や共用スペースを管理するスタッフ
- 学校の教室や実習室を管理する教職員
- 会社の会議室、執務室、倉庫などを管理する社員

### MVPで想定する利用規模

MVPでは、個人、家庭、または小規模なグループでの利用を想定する。

大規模な組織管理、部署管理、承認機能、詳細な権限設定、大量の備品管理は対象外とする。

## 5. ユーザー区分

### 部屋の所有者

部屋を登録したユーザーを、その部屋の所有者とする。

所有者は、部屋の登録、画像変更、メモの登録・編集、共有相手の設定を行う。

### 共有ユーザー

部屋の所有者から共有されたユーザーを、共有ユーザーとする。

共有ユーザーは、共有された部屋とメモの閲覧、メモの登録・編集を行う。

共有相手の追加や変更は、部屋の所有者だけが行えるものとする。

## 6. 主な利用シーン

- アカウントを登録してログインする
- 管理したい部屋の名前と写真を登録する
- 部屋画像上の位置にメモを登録する
- 備品の場所、在庫数、型番、故障状況などをメモする
- 保存したメモピンをタップして内容を確認する
- 保存済みのメモを編集する
- 別端末から同じデータを確認する
- 部屋を他の登録済みユーザーと共有する
- 共有された部屋のメモを確認・編集する
- 設定画面からアカウント情報を確認する

## 7. MVPの範囲

### MVPに含める機能

- アカウント登録
- ログイン
- ログイン状態の保持
- ログアウト
- 部屋登録
- 写真付き部屋一覧
- 部屋詳細表示
- 部屋画像の追加・変更
- 部屋画像上のメモ位置指定
- メモの登録・確認・編集
- ピンカラー10色
- メモへの写真添付
- Cloud Firestoreへのデータ保存
- Cloudinaryへの写真保存
- 複数端末でのデータ同期
- 他の登録済みユーザーとの部屋共有
- 共有された部屋の閲覧・編集
- 設定画面でのアカウント情報表示
- 入力チェック
- 通信・保存エラーの表示

### MVPに含めない機能

- RoomPlanによる3Dスキャン
- AR空間上へのメモ表示
- AIによる家具・備品認識
- 在庫数や型番の専用入力項目
- 在庫・修理履歴
- 予定日の通知
- 組織・部署管理
- 詳細な共有権限
- Android・Web対応

## 11. 制約条件

- 有料サービスを使用しない
- FirebaseとCloudinaryの無料利用範囲内で制作する
- iPhone向けアプリとして制作する
- MVPでは日本語表示に対応する
- MVPでは縦向き画面を基本とする
- iPhone 17 Pro MaxのiOS 26で動作確認する
- 開発期間内に完成可能な機能を優先する
- API Secretなどの秘密情報をGitHubへ登録しない
- アカウントのパスワードをアプリやCloud Firestoreへ保存しない

## 12. 外部サービス

### Firebase Authentication

以下の機能に使用する。

- アカウント登録
- ログイン
- ログイン状態の保持
- ログアウト
- ユーザーIDの取得

### Cloud Firestore

以下のデータの保存と同期に使用する。

- ユーザー情報
- 部屋情報
- メモ情報
- 共有情報
- Cloudinary画像のURLとPublic ID

### Cloudinary

以下の写真の保存と配信に使用する。

- 部屋写真
- メモの添付写真

## 13. 完成条件

以下の操作を最初から最後まで実行できた場合、MVPが完成したものとする。

1. ユーザーがアカウントを登録してログインできる
2. 部屋名と部屋写真を登録できる
3. 登録した部屋を一覧から選択できる
4. 部屋画像上の位置にメモを登録できる
5. タイトル、本文、ピンカラー、添付写真を保存できる
6. 部屋画像上のピンからメモを確認・編集できる
7. アプリを再起動しても保存内容を確認できる
8. 同じアカウントで別端末から保存内容を確認できる
9. 部屋を他の登録済みユーザーと共有できる
10. 共有ユーザーが部屋とメモを確認・編集できる
11. 設定画面からアカウント情報を確認してログアウトできる
