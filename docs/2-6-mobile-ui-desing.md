
# モバイルUI設計

## 1. 概要

本書では、空間メモの各画面に表示する項目と配置を定義する。

## 2. 対象環境

| 項目 | 内容 |
|---|---|
| 対象端末 | iPhone 17 Pro Max |
| 対象OS | iOS 26 |
| 画面方向 | 縦向き |
| UIフレームワーク | SwiftUI |
| アイコン | SF Symbols |
| 写真選択 | PhotosUI |

## 5. 共通UI方針

- iPhoneの縦向き表示を基本とする
- 画面上部にナビゲーションバーを配置する
- 戻る、保存、キャンセルなどの操作位置を画面間で統一する
- アイコンにはApple標準のSF Symbolsを使用する
- ボタンのタップ領域は原則44×44pt以上とする
- 入力項目には内容が分かるラベルを表示する
- 保存処理中は連続操作を防ぐ
- エラー発生時は、原因と対応方法が分かるメッセージを表示する

## 6. 部屋一覧画面

- 部屋写真を縦方向に並べる
- 上下スワイプで部屋を探せるようにする
- 部屋写真上に部屋名と所有・共有の区分を表示する
- 部屋写真をタップすると部屋詳細画面へ移動する
- 画面左上に設定ボタンを配置する
- 画面右上に部屋追加ボタンを配置する

## 7. 部屋詳細画面

- 部屋画像を画面の中心に大きく表示する
- 保存された位置にメモピンを重ねて表示する
- メモピンをタップするとメモ編集画面へ移動する
- 画面右上に共有ボタンと追加ボタンを配置する
- 追加ボタンをタップすると、次のメニューを表示する
  - メモを追加
  - 部屋画像を追加・変更

## 8. メモ編集画面

メモ編集画面では、次の項目を入力または変更できるようにする。

- タイトル
- メモ本文
- ピンカラー
- 添付写真

新規登録と既存メモの編集で同じ画面を使用する。

|---|---|---|
| dusty-pink | ダスティピンク | `#D9A6A6` |

| sage | セージ | `#BDC69D` |
| mint | ミント | `#9FC7B4` |

| mauve | モーヴ | `#C7A4B5` |

## 10. 写真選択画面

写真選択にはiOS標準のPhotosUIを使用するため、独自の写真選択画面は作成しない。

PhotosUIから写真を選択した後、呼び出し元の画面へ戻って選択した写真を表示する。
