## 画面一覧

### 画面構成

「空間メモ」のMVPでは、以下の8画面を使用する。

| 画面ID | 画面名 |
|---|---|
| SCR-001 | ログイン画面 |
| SCR-002 | アカウント登録画面 |
| SCR-003 | 部屋一覧画面 |
| SCR-004 | 部屋登録画面 |
| SCR-005 | 部屋詳細画面 |
| SCR-006 | メモ編集画面 |
| SCR-007 | 共有管理画面 |
| SCR-008 | 設定画面 |

## SCR-001 ログイン画面

| 項目 | 内容 |
|---|---|
| 目的 | 登録済みのアカウントでアプリへログインする |
| 表示項目 | アプリ名、メールアドレス入力欄、パスワード入力欄、ログインボタン、アカウント登録画面へのリンク、エラーメッセージ |
| 操作内容 | メールアドレスを入力する、パスワードを入力する、ログインする、アカウント登録画面へ移動する |
| 遷移先 | 部屋一覧画面、アカウント登録画面 |
| 備考 | ログイン済みの場合は、この画面を表示せず部屋一覧画面を表示する |

## SCR-002 アカウント登録画面

| 項目 | 内容 |
|---|---|
| 目的 | 空間メモを利用するためのアカウントを新しく作成する |
| 表示項目 | ユーザー名入力欄、メールアドレス入力欄、パスワード入力欄、パスワード確認入力欄、登録ボタン、ログイン画面へのリンク、エラーメッセージ |
| 操作内容 | ユーザー情報を入力する、アカウントを登録する、ログイン画面へ移動する |
| 遷移先 | 部屋一覧画面、ログイン画面 |
| 備考 | Firebase Authenticationでアカウントを作成し、ユーザー名などをCloud Firestoreへ保存する |

## SCR-003 部屋一覧画面

| 項目 | 内容 |
|---|---|
| 目的 | 登録済みまたは共有された部屋を写真から探して選択する |
| 表示項目 | 画面タイトル、部屋写真、部屋名、所有・共有の区分、部屋追加ボタン、設定ボタン、読み込み中表示、データがない場合の案内 |
| 操作内容 | 縦スワイプで部屋一覧をスクロールする、部屋写真をタップする、部屋追加ボタンを押す、設定ボタンを押す |
| 遷移先 | 部屋詳細画面、部屋登録画面、設定画面 |
| 備考 | 自分が所有する部屋と共有された部屋を判別できるように表示する |

## SCR-004 部屋登録画面

| 項目 | 内容 |
|---|---|
| 目的 | 新しい部屋を登録する |
| 表示項目 | 部屋名入力欄、部屋写真、写真選択ボタン、保存ボタン、キャンセルボタン、アップロード中表示、エラーメッセージ |
| 操作内容 | 部屋名を入力する、写真ライブラリから写真を選択する、選択した写真を確認する、部屋を保存する、登録をキャンセルする |
| 遷移先 | 部屋一覧画面、iPhone標準の写真選択 |
| 備考 | 部屋名と部屋写真を必須項目とする |

## SCR-005 部屋詳細画面

| 項目 | 内容 |
|---|---|
| 目的 | 部屋画像と、その場所に登録されているメモを確認する |
| 表示項目 | 部屋名、部屋画像、メモピン、追加ボタン、共有ボタン、読み込み中表示、エラーメッセージ |
| 操作内容 | メモピンをタップする、追加ボタンから「メモを追加」または「部屋画像を追加・変更」を選択する、共有ボタンを押す |
| 遷移先 | メモ編集画面、共有管理画面、iPhone標準の写真選択 |
| 備考 | メモ追加時は、部屋画像上の位置をタップしてからメモ編集画面を表示する |

## SCR-006 メモ編集画面

| 項目 | 内容 |
|---|---|
| 目的 | 選択した位置に保存するメモを新規登録または編集する |
| 表示項目 | タイトル入力欄、メモ本文入力欄、ピンカラー10色、選択中カラー、添付写真、写真選択ボタン、保存ボタン、キャンセルボタン、処理中表示、エラーメッセージ |
| 操作内容 | タイトルを入力する、本文を入力する、ピンカラーを選択する、写真を添付する、メモを保存する、編集をキャンセルする |
| 遷移先 | 部屋詳細画面、iPhone標準の写真選択 |
| 備考 | タイトル、ピンカラー、ピン位置を必須項目とする。本文と添付写真は任意項目とする |

## SCR-007 共有管理画面

| 項目 | 内容 |
|---|---|
| 目的 | 選択した部屋を他の登録済みユーザーと共有する |
| 表示項目 | 部屋名、部屋の所有者、共有相手のメールアドレス入力欄、共有ボタン、共有中ユーザー一覧、処理中表示、エラーメッセージ |
| 操作内容 | 共有相手のメールアドレスを入力する、ユーザーを部屋へ追加する、共有中のユーザーを確認する |
| 遷移先 | 部屋詳細画面 |
| 備考 | 共有相手の追加は部屋の所有者だけが実行できる。共有ユーザーには共有操作を表示しない |

## SCR-008 設定画面

| 項目 | 内容 |
|---|---|
| 目的 | ログイン中のアカウントとアプリの情報を確認する |
| 表示項目 | ユーザー名、メールアドレス、アプリ名、アプリバージョン、ログアウトボタン |
| 操作内容 | アカウント情報を確認する、ログアウトする |
| 遷移先 | ログイン画面、部屋一覧画面 |
| 備考 | パスワード再設定、アカウント削除、ユーザー名変更は時間に余裕があれば追加する |

## 共通して使用する標準画面

### iPhone標準の写真選択

PhotosUIが提供する標準画面を使用する。

この画面はアプリ独自の画面ではないため、画面数には含めない。

使用する場面は以下のとおりである。

- 部屋登録時の写真選択
- 部屋画像の追加・変更
- メモへの写真添付

## 共通表示

各画面では、必要に応じて以下の表示を行う。

- 読み込み中表示
- 保存中表示
- 写真アップロード中表示
- 入力エラーメッセージ
- 通信エラーメッセージ
- データが存在しない場合の案内
- 操作完了メッセージ
